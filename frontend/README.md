# Owl-Player Frontend

Next.js frontend application for the video streaming platform.

## 🚀 Quick Start

```bash
# Install dependencies
npm install

# Start development server
npm run dev
```

## 📁 Pages

- `/` - Home page with video library
- `/upload` - Video upload page
- `/watch/[id]` - Video player page

## 🎨 Styling

Built with Tailwind CSS for modern, responsive design.
